# VisRobot

VisRobot is a public research showcase from **deepdive_kai**, centered on reliable bimanual garment manipulation and the systems work required to move from data to physical deployment.

The website presents:

- the garment data and evaluation pipeline;
- bimanual VLA policy learning and deployment;
- motion-stability measurement and mitigation;
- CRAVE and offline reinforcement-learning studies;
- predictive-representation research, negative results, and evidence boundaries.

## Public release boundary

This repository contains only the generated static website and public-facing evidence assets. It does **not** contain private datasets, model checkpoints, training code, robot-control code, deployment services, internal experiment plans, or the `deepdive_kai` source repository.

The published site is built from [`site/`](site/). Pushes to `main` are deployed through GitHub Pages.

## Project identity

**VisRobot — a deepdive_kai project**

Task A refers to garment flatten-and-fold. Task N refers to nail-art manipulation. Public claims retain their evidence status and protocol boundaries.
