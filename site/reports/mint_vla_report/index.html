Actionable Futures

预测未来表征何时真正约束 Vision–Language–Action 控制？

论文已经从“MINT-VLA 是否提升 π0.5”改写为一个更完整的问题：未来表征可预测、训练 package 有效、 策略使用条件内容、以及具体组件产生收益，是四个彼此独立的命题，而不是逐级必需的证据阶梯。当前最强正证据来自 released LaWAM： 固定 checkpoint 下，episode-matched condition 为 94.00%，同任务 shuffled 内容为 40.33%。与此同时，MINT-VLA 和 PredictiveActionAdapter 则表明，在当前审计设置中，表示预测成立并不自动转化成可复制控制收益。 TG4 正在做来源分解，完成前不归因。

01 · Executive summary

现在真正取得了什么结论

我们不再把所有结果压缩成“world model 有效或无效”。证据显示：released LaWAM checkpoint 强烈依赖特定的 episode-matched predicted condition；但 MINT-VLA 和 PredictiveActionAdapter 都没有通过独立 matched-seed 方法增益门槛。 因而论文的核心是区分可预测性、控制效用、内容因果性和组件来源，而不是包装一个统一正结果。

当前最强结论：一个 released LaWAM checkpoint 的高成功率强烈依赖 episode-matched predicted condition；TG1A 的 paired shuffled、null 和 persistence 干预共同支持这一点。不同 episode 的 shuffle 也可能破坏 scene coherence 或产生分布外条件，因此该结果不能单独证明 endpoint 语义本身是原因，也不能归因到某个训练组件。

02 · Claim–evidence matrix

四个问题独立回答不同命题

1. Predictability

预测 latent 是否优于 persistence、错误动作或 masked action？

只证明未来表示被学到。

2. Matched utility

candidate 与独立训练的 baseline 在相同 training seeds 下是否提高闭环成功率？

必须纳入 baseline training variation。

3. Content use

固定 checkpoint 和场景后，正确内容是否优于 shuffled、null 与 persistence？

识别策略是否使用特定内容。

4. Source attribution

pretraining、auxiliary shaping、inference conditioning 和 interaction 各自贡献多少？

TG4 完成前保持 unresolved。
不是线性阶梯：训练 package 可能通过表征塑形获益而在推理时忽略 condition；固定 checkpoint 也可能依赖 condition，却没有优于 matched no-WM training。需要哪类证据取决于论文正在提出哪类 claim。
时间契约：released LaWAM 的 H=E=36，目标位于 offset 35；历史 local setup 的 H=50、E=36； recurrence milestone 平均位于 117.45 frames 之后。这个差异是已测量事实，但“时间错位导致无效”仍只是待验证解释。

03 · Predictive interfaces

论文比较的三种条件位置

01

LaWAM endpoint grid

预测完整 future visual grid，并与当前 grid、VLM tokens 一起进入 flow action expert。

02

MINT-VLA token

在当前 π0.5 编码器空间预测 variable-horizon milestone，并压缩为一个 VLM prefix token。

03

PredictiveActionAdapter

从当前 grid 与 noisy action proposal 预测 future-grid residual，再逐 action token 注入零初始化修正。

04

Causal interventions

用 shuffled、null、persistence、zero route 和 masked action 分别测试内容、路径与动作条件。

共同原则 representation metric、单 seed 增益或 public checkpoint 分数都不能替代 matched utility 与 content-use gate。

PredictiveActionAdapter 为什么仍是架构贡献

同一个 adapter 在训练时调用两次：clean expert action chunk 产生 future-grid prediction loss；noisy flow proposal 产生逐动作 residual route。推理时没有 clean action，adapter 在每个 denoising step 上使用当前 proposal 重新预测并修正。 inherited visual features stop-gradient，route 输出层严格零初始化，因此初始策略值与原 π0.5 完全一致。该设计成立且只增加 0.50% 参数，但这里的“保持”只成立于初始化时；训练后策略会改变。当前证据不支持稳定控制增益、可用未来动力学或正确内容因果性。

05 · Claim boundary

论文可以说什么，不能说什么

证据支持

  • Released LaWAM checkpoint 强烈依赖 episode-matched predicted condition。
  • MINT-VLA 学到了优于 persistence 的 held-out milestone 表征。
  • PredictiveActionAdapter 的 future-target prediction 对 expert action 有小而可检测的敏感性。
  • PredictiveActionAdapter 是低侵入、初始化时保持 base function 的 proposal-conditioned 控制接口。
  • 未来表征可预测并不保证 independently matched control utility。
  • 训练 seed 与任务级退化必须与宏平均并列报告。

证据不支持

  • LaWAM 的提升已经归因于 inference conditioning 或 auxiliary loss。
  • TG1A 已经把 endpoint 语义与 scene coherence / 分布外扰动完全分离。
  • LMWM 无效是由 milestone 超出 action chunk 导致。
  • MINT-VLA 或 PredictiveActionAdapter 稳定提升了 π0.5。
  • 一个 public system score 能识别某个 world-model 组件。
  • RoboTwin 六任务结论可直接推广到其他 VLA 或真实机器人。

06 · Open question

TG4 仍需回答来源归因

Clean base

不继承 predictive pretraining 的兼容基础模型。

Auxiliary only

保留预测辅助塑形，但关闭推理 future route。

Conditioning only

保留 future route，但移除预测辅助损失。

Full + null controls

分离总效应、parameter-matched capacity 与 interaction。
